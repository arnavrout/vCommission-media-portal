🚀 Project Overview

vCommission Media is a frontend project developed using cutting-edge web technologies to ensure scalability, modularity, and responsiveness.
The app utilizes React 18, Vite, and Tailwind CSS, along with several utility and UI libraries for fast, optimized, and maintainable development.

🧠 Tech Stack & Tools
Frontend Framework & Build Tool

React 18.3.1 – UI library powering the project

Vite – Next-generation build tool and development server

TypeScript – Type-safe JavaScript for maintainable code

Styling & UI

Tailwind CSS – Utility-first CSS framework

shadcn-ui – Accessible component library built on Radix UI primitives

Radix UI – UI primitives (Dialog, Dropdown, Accordion, etc.)

Framer Motion v12.23.24 – Animation library for smooth transitions

tailwindcss-animate – Extra animation utilities

UI Components & Icons

Lucide React v0.462.0 – Modern icon set

Recharts v2.15.4 – Data visualization and charts

Sonner – Toast notification system

Vaul – Drawer component

Embla Carousel – Carousel functionality

External APIs

DummyJSON API – Product and data mock API

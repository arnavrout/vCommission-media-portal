# 🚀 vCommission Media

vCommission Media is a **frontend project** built using modern web technologies to ensure **scalability**, **modularity**, and **responsiveness**. The application leverages React 18, Vite, and Tailwind CSS along with several UI and utility libraries for **fast, optimized, and maintainable development**.

---

## 🧠 Tech Stack & Tools

### Frontend Framework & Build Tool
- **React 18.3.1** – UI library powering the project  
- **Vite** – Next-generation build tool and development server  
- **TypeScript** – Type-safe JavaScript for maintainable code  

### Styling & UI
- **Tailwind CSS** – Utility-first CSS framework  
- **shadcn-ui** – Accessible component library built on Radix UI primitives  
- **Radix UI** – UI primitives (Dialog, Dropdown, Accordion, etc.)  
- **Framer Motion v12.23.24** – Animation library for smooth transitions  
- **tailwindcss-animate** – Additional animation utilities  

### UI Components & Icons
- **Lucide React v0.462.0** – Modern icon set  
- **Recharts v2.15.4** – Data visualization and charts  
- **Sonner** – Toast notification system  
- **Vaul** – Drawer component  
- **Embla Carousel** – Carousel functionality  

### External APIs
- **DummyJSON API** – Product and data mock API  
  [https://dummyjson.com/products](https://dummyjson.com/products)

---

## ⚡ Features
- Responsive Dashboard and Product pages  
- Interactive Charts and Graphs (BarChart, PieChart)  
- Dynamic Product Listing with Search & Pagination  
- Shopping Cart with Toast Notifications  
- Theme Toggle (Light/Dark)  
- Animated Transitions using Framer Motion  
- Modular and maintainable architecture using TypeScript
